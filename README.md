# Ultimate Toolkit V3

**By Bhaskar**

A graphical Windows administration and troubleshooting toolkit built using Batch scripting and PowerShell.

## Features

- System Administration
- Network Diagnostics
- Windows Repair
- Security & Windows Defender
- Performance Monitoring
- Storage & Disk Management
- User & Account Management
- Backup & Restore
- Drive & Hardware Information
- Windows Update
- Office & Outlook Utilities
- Printer Management
- Remote Access
- BIOS / UEFI / Boot Tools
- Registry & Group Policy
- Windows Services

## Requirements

- Windows 10 or Windows 11
- Windows PowerShell
- Administrator privileges for certain operations

## How to Run

1. Download `Ultimate_Toolkit_V3_By_Bhaskar.bat`.
2. Double-click the BAT file.
3. Run as Administrator when required.
